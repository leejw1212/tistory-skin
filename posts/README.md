# 📤 posts/

`tools/build-post.mjs` 가 만든 글 초안과, 가공이 끝난 사진이 쌓이는 곳입니다.

```
posts/2026-09-21-여의도-한강공원-5k/
  post.md      글 초안 — <!-- WRITE: ... --> 만 채우면 발행 가능
  data.json    계산 결과 전부 (스플릿 · 사진별 km · 커버 후보)
  photos/      1600px 로 줄이고 EXIF 를 지운 사진
```

## 사진이 여기 있어야 하는 이유

티스토리는 2024년에 파일 첨부 API 까지 닫혔습니다. 그래서 사진을 티스토리에 올리는 대신
**이 저장소에 두고 jsDelivr CDN 으로 불러옵니다.**

```
https://cdn.jsdelivr.net/gh/leejw1212/tistory-skin@main/posts/<폴더>/photos/01-....jpg
```

`post.md` 안의 사진 주소가 이미 이 형식으로 들어 있습니다.

> ⚠️ **글을 발행하기 전에 사진이 `main` 에 올라가 있어야 합니다.**
> 아직 브랜치에만 있으면 CDN 주소가 404 가 됩니다.
> 브랜치 주소로 먼저 확인하고 싶으면 `--cdn-ref <브랜치이름>` 을 주세요.

## 발행 순서

1. `post.md` 의 `<!-- WRITE: ... -->` 를 채웁니다
2. 사진과 함께 `main` 에 푸시합니다
3. 티스토리 **글쓰기 → 마크다운 모드** 에서 `post.md` 전체를 붙여넣습니다
4. 카테고리 `러닝코스`, 첫 태그를 지역명으로, 대표 이미지 지정 후 발행
5. 생긴 글 주소를 `images/courses.json` 의 `link` 에 넣고 티스토리 [스킨 편집 → 파일 업로드] 에 올립니다
   (`/12` 또는 `/entry/제목` 형식 — 카테고리 경로가 아닙니다)
