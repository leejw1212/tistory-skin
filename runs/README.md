# 📥 runs/

러닝 한 번 = 폴더 하나. 여기에 재료를 넣고 도구를 돌리면 글 초안이 나옵니다.

```
runs/2026-09-21-여의도/
  activity.tcx      TCX 1개        — 애플 헬스 → RunGap → Dropbox 에 올라온 파일
  IMG_0001.jpg      사진 여러 장    — 순서 상관 없습니다
  IMG_0002.jpg
  notes.md          소감 (선택)     — 말투 그대로, 메모처럼 써도 됩니다
  meta.json         추가 정보 (선택)
```

> Dropbox 의 `/앱/RunGap/export/` 에 `2026-09-21_08-28-48_hk_1789946928.tcx` 같은 이름으로 쌓입니다.
> 파일명 앞부분이 이미 한국 시간이라 어느 러닝인지 바로 알 수 있습니다.
> GPX 를 넣어도 동작합니다 — 다만 심박·케이던스는 TCX 에만 있습니다.

```bash
node tools/build-post.mjs runs/2026-09-21-여의도
```

→ `posts/<날짜-코스아이디>/post.md` 와 가공된 사진이 만들어지고, `images/courses.json` 이 갱신됩니다.

## TCX 가 GPX 보다 나은 이유

| | GPX | TCX |
| --- | --- | --- |
| 좌표 · 고도 · 시각 | ✅ | ✅ |
| **기기가 측정한 거리** | ❌ (좌표로 계산 — 실제보다 짧음) | ✅ |
| **심박** | ❌ | ✅ 평균 · 최고 |
| **케이던스** | ❌ | ✅ |
| **칼로리** | ❌ | ✅ |

TCX 를 넣으면 심박·케이던스·칼로리가 글의 정보 표에 자동으로 들어갑니다.

## 걷기나 실내운동은 알아서 걸러집니다

RunGap 은 애플 헬스의 활동을 전부 내보냅니다. 도구가 페이스와 트랙 유무로 판단해서
러닝이 아니면 경고를 띄웁니다. 쌓인 파일 중에 뭐가 글감인지 먼저 보려면:

```bash
node tools/tcx-report.mjs <TCX 폴더> --runs
```

## 사진은 순서대로 안 넣어도 됩니다

촬영 시각(EXIF)과 트랙 시각을 맞춰서 **사진이 코스의 몇 km 지점인지 자동으로 계산**합니다.

| 언제 찍은 사진인가 | 글의 어디로 가는가 |
| --- | --- |
| 달리기 시작 **전** | `🅿️ 주차 & 출발 지점` |
| 달리는 **중** | `🏃 코스 따라가기` 의 해당 km 구간 |
| 완주 **후** | `📸 러닝 기록` |
| 촬영 시각이 없음 | `📸 러닝 기록` 맨 뒤 |

> ⚠️ 폰 시계가 맞아야 합니다. 해외에서 찍었거나 시각이 어긋나면 `--tz` 로 분 단위 오프셋을 주세요.
> (기본값은 한국 `--tz 540`)

## 🔒 위치정보는 자동으로 지웁니다

사진의 EXIF GPS 는 코스 매칭에 쓴 뒤 **출력 파일에서 제거**됩니다.
집 근처를 달린 사진에 좌표가 남아 있으면 사는 곳이 그대로 공개되기 때문입니다.
같이 리사이즈(긴 변 1600px)와 회전 보정도 합니다.

`sharp` 가 설치돼 있어야 합니다. 한 번만 실행하세요:

```bash
npm install
```

설치하지 않으면 원본이 그대로 복사되고 **EXIF 가 남습니다.** 도구가 경고를 띄웁니다.

## meta.json (선택)

아는 정보를 미리 적어두면 초안의 빈칸이 그만큼 줄어듭니다.

```json
{
  "title": "여의도 한강공원 5K",
  "place": "여의도 한강공원 (서울 영등포구)",
  "surface": "우레탄 + 보도블록",
  "parking": "여의도한강공원 제1주차장 · 30분 1,000원",
  "transit": "5호선 여의나루역 2번 출구 → 도보 5분",
  "water": "3곳 (시작점 · 2km · 4km)",
  "toilet": "4곳",
  "segments": { "2": "물빛광장 구간", "4": "마포대교 방향" }
}
```

`segments` 는 구간 끝 km 를 키로 두면 소제목에 붙습니다 — `### 0 ~ 2km · 물빛광장 구간`
