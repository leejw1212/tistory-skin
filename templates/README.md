# ✍️ 글 양식 사용법

달리고 와서 사진만 있으면 바로 쓸 수 있도록 만든 마크다운 양식입니다.

| 파일 | 카테고리 | 쓰는 때 |
| --- | --- | --- |
| [러닝코스.md](러닝코스.md) | 러닝코스 | 코스를 소개할 때 (주차 · 접근성 · 난이도 중심) |
| [맛집.md](맛집.md) | 맛집 | 러닝 후 들른 가게를 소개할 때 |
| [제품리뷰.md](제품리뷰.md) | 제품리뷰 | 러닝화 · 장비 리뷰 |

---

## 📝 쓰는 순서

1. **티스토리 글쓰기 → 우측 상단에서 `마크다운` 모드로 변경**
2. 해당 양식 파일의 내용을 전부 복사해 붙여넣기
3. 사진을 찍은 순서대로 `![설명](사진1.jpg)` 자리에 드래그해서 넣기
   - **대괄호 안에 적은 설명이 사진 아래 캡션으로 표시됩니다**
4. 표의 값만 실제 정보로 바꾸기
5. 발행

---

## 🎨 양식이 스킨에서 어떻게 보이나요

양식에 쓰인 마크다운 문법은 스킨이 알아서 예쁘게 바꿔 줍니다.

### 1. 정보 표 → 카드

`## 📍 코스 정보` 아래의 `| 항목 | 내용 |` 표는 **아이콘이 붙은 카드 그리드**로 바뀝니다.
`★★☆☆☆` 처럼 쓰면 별점 위젯이 됩니다.

> 표의 제목 줄은 반드시 `| 항목 | 내용 |` 두 칸으로 두세요. 제목이 `코스 정보`, `기본 정보`,
> `가게 정보`, `제품 정보`, `스펙` 중 하나면 카드로 변환됩니다.

### 2. 인용구 → 콜아웃 박스

맨 앞 이모지에 따라 색이 달라집니다.

| 쓰는 법 | 결과 |
| --- | --- |
| `> 💡 팁 ...` | 노란 팁 박스 |
| `> ⚠️ 주의 ...` | 주황 경고 박스 |
| `> ✅ 체크 ...` | 초록 확인 박스 |
| `> 🅿️ 주차 ...` | 파란 주차 박스 |
| `> 🚇 접근성 ...` | 하늘색 교통 박스 |
| `> 📌 포인트 ...` | 분홍 핵심 박스 |
| `> 🍽️ 맛집 ...` | 주황 맛집 박스 |

### 3. 사진 2장 이상을 연달아 → 갤러리 그리드

```
![주차장 입구](사진1.jpg)
![요금 안내판](사진2.jpg)
```

빈 줄 없이 연달아 쓰면 나란히 배치됩니다. 사진을 누르면 크게 볼 수 있어요.

### 4. `[course:아이디]` → 코스 지도

그 줄 자리에 **GPX 경로 지도**가 그려집니다.
아이디는 `tools/gpx-studio.html` 이나 `node tools/build-courses.mjs` 가 알려 줍니다.

> 이 줄을 빼도 괜찮습니다. 글 주소나 제목이 코스와 맞으면 스킨이 알아서 지도를 넣어 줍니다.

### 5. 체크리스트

`- [x] 완료`, `- [ ] 미완료` 로 쓰면 체크박스로 표시됩니다.

### 6. 목차

`##`, `###` 제목이 3개 이상이면 글 맨 위에 **목차**가 자동으로 생깁니다.

## 🔗 러닝코스 ↔ 맛집 자동 연결

`images/courses.json` 에 코스와 맛집 좌표가 들어 있으면 **글을 쓸 때 아무것도 안 해도**
아래 블록이 자동으로 붙습니다.

- **러닝코스 글** → 코스 중간 지점에서 5km 이내 맛집 목록
- **맛집 글** → 그 맛집에서 5km 이내 러닝 코스 목록

좌표가 없으면 첫 번째 태그를 기준으로 `○○ 맛집` 검색 링크가 대신 표시됩니다.
그래서 **첫 번째 태그는 지역명**(예: `여의도`)으로 두는 게 좋습니다.

---

## 🔗 발행 후 — 글 주소 연결하기

지도에서 코스를 눌렀을 때 글로 이동하게 하려면, 발행된 글 주소를
`images/courses.json` 의 `link` 에 넣어야 합니다.

| 주소창에 보이는 것 | `link` 에 적을 값 |
| --- | --- |
| `https://내블로그.tistory.com/12` | `/12` |
| `https://내블로그.tistory.com/entry/여의도-한강-5k` | `/entry/여의도-한강-5k` |

> 카테고리 경로(`/category/러닝코스/12`)는 글 주소가 아닙니다.

`tools/gpx-studio.html` 에서 기존 `courses.json` 을 불러와 `글 주소` 칸만 채우고
다시 내려받으면 됩니다. 비워두면 코스를 눌렀을 때 제목으로 블로그 내 검색이 열립니다.

## 📌 카테고리 이름

스킨 메뉴가 아래 이름을 기준으로 동작합니다. 티스토리 관리에서 똑같이 만들어 주세요.

- `러닝코스`
- `맛집`
- `제품리뷰`

다른 이름을 쓰고 싶다면 `skin.html` 의 메뉴 링크와 `images/script.js` 의 `CATEGORY_URLS` 를 함께 바꾸세요.
